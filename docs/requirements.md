# Meta Cue 首版需求

经用户逐项确认，2026-11-21。

- 目标：当前 Manjaro / Plasma 6.7.5 / Wayland，保留系统原生仅图标任务管理器。
- 单独按住任一 Meta 300 ms 后提示；松开立即隐藏。
- 其他键（包含 Ctrl、Alt、Shift）取消当前手势，松开 Meta 后才能重试。
- 短按 Meta 和组合快捷键行为不变；提示触发后松开 Meta 不弹出应用启动器。不拦截、不注入按键。
- 只提示实际绑定 Meta+1…9 的项目，包括固定启动器和合并任务；不占用 Meta+0。
- 数字位于图标上沿，高对比，无动画；不影响点击、悬停、拖动。
- 编号跟随原生模型；状态不确定时隐藏。
- 仅现有底部任务栏；不复制图标，不唤出隐藏面板。
- 适应当前三屏、145% / 170% 混合缩放；面板或输出变化时重新定位。
- 锁屏、休眠、会话变化清除状态，回来后需新一次按住。
- 完成验证后登录自启；无主窗口；配置文件调整延迟；可停用、卸载。
- 不改写系统任务栏文件。独立 KWin 插件和不可见 Plasma 伴随组件。
- 验收包括真实桌面输入、对齐、鼠标行为和会话恢复；自动测试不替代全部验收。

## 更新需求

- Meta Cue 提示一旦触发，松开 Meta 只隐藏提示，不弹出应用启动器。
- 未触发提示的短按 Meta 继续打开启动器；抑制状态不延续到下一次按键。
- 撤销 Meta＋反引号的特殊取消功能，保留其原有 KDE 快捷键行为。
